# Description
The Chinese Social Credit Test for IBM PC is a quiz game designed to work on old PCs.

# System requirements
- IBM PC or later/8088 or later
- 64 KB of RAM or above (as tested on PCjs for IBM PC of 1981 and 86Box for IBM XT of 1986; unconfirmed)
- CGA (Mode is 80x40), EGA, MDA, VGA, or any graphics card
- Two 5¼ floppy drives (360Kb)
- IBM DOS/MS-DOS 2.00 or above
